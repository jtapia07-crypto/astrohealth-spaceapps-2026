# AstroHealth Guardian

**Live Web App:** [https://jtapia07-crypto.github.io/astrohealth-spaceapps-2026/](https://jtapia07-crypto.github.io/astrohealth-spaceapps-2026/)

In space, every signal from the body matters. That's why we created **AstroHealth Guardian**, an app that monitors astronauts in real time.

- **HUMAN:** Its interactive body map displays the status of each organ using different colors and explains, in simple terms, how to prevent a medical emergency.
- **SHIP:** Live space data monitors the cabin environment and space weather telemetry in real time.
- **GARDEN:** Transforms sleep, water, and mood into regenerative well-being.

Connected to NASA data on orbit, the Moon, and Mars — **body, spacecraft, and mind, united in a single system.**
